# GTA · 上海像素城（GTA Shanghai Pixel City）

> 单人开放世界 · 2D 像素风 · 全 NPC · 浏览器直接玩（HTML + Canvas + JS，零依赖）
> 地图覆盖上海 12 个行政区，每区一张独立小地图，通过总览地图/地铁传送切换。

---

## 🎮 玩法与操作

| 按键 | 功能 |
|---|---|
| `W A S D` / 方向键 | 移动 / 开车（W加速 · S刹车 · A/D转向） |
| `Shift` | 跑步 |
| `E` | 上/下车 |
| `F` | 互动（接任务 / 查看产业 / 地铁传送 / 进入区域） |
| `M` | 打开全城区域传送（相当于地铁/轮渡） |
| `B` | 产业经营菜单 |
| `Tab` | 暂停菜单（存档 / 读档 / 返回标题） |
| `Esc` | 关闭面板 |

### 核心玩法
- **开放世界探索**：12 个行政区（杨浦、虹口、黄浦、徐汇、静安、普陀、长宁、陆家嘴、世博、前滩、崇明、临港），地标按真实上海位置布局。
- **经营产业**：便利店、加油站、改装车行、货运站、夜店、健身房——购买后每 10 秒自动产出收益，可升级、可出售。
- **任务系统**：货运配送（开车送货）、安保押运（护送运钞车）、街头竞速（与 NPC 赛车），限时完成拿奖金。
- **通缉与警察**：撞倒市民会引来目击者报警，通缉等级 1~5 星，星级越高警车越多越快；甩开警察风头会过去，被抓则罚款。
- **载具系统**：满街 NPC 车辆可抢？不——是**借开**（合规版），上车开车、下车还车。
- **存档**：浏览器 localStorage 自动/手动存档，产业所有权跨区保留。

## 🗺️ 地图设计

- 布局还原、面积压缩：每区 400×400 格（1 格 ≈ 8px），地标、水域（黄浦江、苏州河、滴水湖、长江口）、道路关系按真实上海相对位置生成。
- 支持矩形水域 + 圆形水域（临港滴水湖）、道路自动架桥。
- 总览图：黄浦江隔开浦西/浦东，崇明为北部岛屿，临港在东南，走上去按 F 进入。

```
    └── logic.js        # 核心逻辑测试（NPC/产业/通缉/任务/驾驶速度）
```

## 🚀 运行方式

### 本地直接玩
双击 `index.html` 用浏览器打开即可（推荐 Chrome/Edge）。

### 部署到 Netlify（免费，生成分享链接）
方式一 · 拖拽（最简单）：
1. 打开 [app.netlify.com/drop](https://app.netlify.com/drop)
2. 把整个 `gta-shanghai` 文件夹**拖进去**
3. 稍等几秒即生成 `https://xxx.netlify.app` 链接，把链接发给朋友就能玩

方式二 · Netlify CLI：
```bash
npm i -g netlify-cli
netlify deploy --dir gta-shanghai --prod   # 首次需登录授权
```
或先 `netlify deploy --dir gta-shanghai` 生成预览链接。

> 注意：无需构建步骤、无服务器，纯静态托管。存档存在各玩家自己的浏览器里，互不影响。

## ⚖️ 合规说明

本游戏为**虚构像素沙盒**：不包含抢劫、诈骗等真实犯罪玩法，产业与任务均为合法经营/运输/竞速内容；撞人、违章等仅作为轻度追逐玩法，被警方控制以「缴纳罚金」收场。地图与真实上海仅作地名致敬，无真实测绘还原。

## 🛠️ 技术要点（供二次开发）

- 性能：每张地图生成后预渲染为整张离屏位图（3200×3200），运行时仅裁剪可视区域绘制，流畅 60fps。
- 存档：`localStorage` 键 `gta-shanghai-save-v1`，跨区产业所有权存于 `ownership` 字段。
- 新增行政区：在 `js/config.js` 的 `MAPS` 中加一段配置（道路间距/水域矩形/地标/产业/任务/警局/传送点/出生点）即可，地图自动生成。
- 测试：`node test/smoke.js && node test/logic.js`（逻辑测试已 mock DOM 环境，可离线跑）。
