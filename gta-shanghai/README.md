# GTA · 上海像素城（GTA Shanghai Pixel City）

> 单人开放世界 · 2D 像素风 · 全 NPC · 浏览器直接玩（HTML + Canvas + JS，零依赖）
> 地图覆盖上海 12 个行政区 + **第二城市沈阳**，每区一张独立小地图（按真实区划形状裁剪），通过城市传送面板/地铁传送切换。

---

## 🎮 玩法与操作

| 按键 | 功能 |
|---|---|
| `W A S D` / 方向键 | 移动 / 开车（前进/刹车/转向） |
| `1~5` | 挂前进档（1 最慢 ~ 5 最快，档位越高极速越高） |
| `N` | 挂空档（无动力滑行） |
| `V` | 挂倒档（按住 W 倒车） |
| `空格` | 手刹（急减速；**跑车**在转弯+速度≥14 时按住=漂移） |
| `Q` / `R` | 左/右转向灯（HUD 有指示灯） |
| `Shift` | 跑步 |
| `E` | 上/下车 |
| `F` | 互动（接任务 / 查看产业 / 地铁传送 / 进入区域） |
| `G` | 与路人交谈（随机台词，偶尔有小费） |
| `M` | 打开城市传送（上海 12 区 / 沈阳 / 全览图） |
| `B` | 产业经营菜单 |
| `C` | 生涯统计（任务/收入/距离/被捕） |
| `H` | 操作帮助 |
| `Tab` | 暂停菜单（存档 / 读档 / 返回标题） |
| `Esc` | 关闭面板 |

### 核心玩法
- **开放世界探索**：12 个行政区（杨浦、虹口、黄浦、徐汇、静安、普陀、长宁、陆家嘴、世博、前滩、崇明、临港），地标按真实上海位置布局，**行政区轮廓按真实区划形状裁剪**（区外为郊野，不可通行）。
- **第二城市 · 沈阳**：传送面板「第二城市」进入，聚焦三大地点——**丁香湖**（椭圆湖面 + 环湖公园绿地）、**中海城**（大型住宅小区，含内部路网与楼栋群）、**三台子万象汇**（商业地标）；高铁站传送点可一键返回上海。
- **经营产业**：便利店、加油站、改装车行、货运站、夜店、健身房——购买后每 10 秒自动产出收益（**跨区照常收租**），可升级、可出售。
- **买房收租**：全城 14 处楼盘（外滩花园洋房/陆家嘴大平层/中海城住宅…）可购买，每 30 秒收房租（**跨区照收**），可回家、可出售——"睡后收入"双通道（产业 10s + 房产 30s）。
- **任务系统**：货运配送、安保押运、街头竞速、**出租车载客**、**追捕小偷**（小偷跑得比人快，开车撞停或步行贴近按 F 制服），限时完成拿奖金。
- **随机街头失物**：路边会刷新 💼 失物包裹（金色闪烁箱），步行或开车碰到即拾取，获得 ¥80~200 感谢金。
- **通缉与警察**：撞倒市民会引来目击者报警，通缉等级 1~5 星，星级越高警车越多越快；甩开警察风头会过去，被抓则罚款。
- **载具系统**：满街 5 种载具（轿车/跑车/出租车/卡车/警车）可**借开**（合规版），速度与体型各不相同。
- **真实驾驶模拟（🚗）**：手动挡玩法——上车后先挂档再踩油门（`1~5` 前进档，档位越高极速越高；`N` 空档滑行；`V` 倒档）。**手刹**（空格）可急减速；**跑车**专属**漂移**：转弯中 + 速度 ≥14 + 按住空格 → 车身沿漂移动量滑行、转向更灵敏，路面留下渐隐胎痕。普通车/卡车/出租车无法漂移。
- **转向灯（💡）**：按 `Q`/`R` 打左/右转向灯，车头车尾同侧黄灯闪烁（仅玩家车辆显示，HUD 有指示灯）。
- **天气与季节（🌦️）**：40 游戏天换一季（春→夏→秋→冬）。**上海**小概率触发**台风**（风力随机 8~12 级，持续约 1 分钟）：屏幕斜雨丝、NPC 车与玩家车速变慢、行人会被风推着走；**沈阳**仅在**冬季**随机下雪（雪量随机 1~3 级）：大地覆雪、雪花飘落、NPC 车减速。
- **沈阳严寒（🥶）**：沈阳冬天在室外会持续累积寒冷值（雪天累积更快）；**寒冷 ≥60** 失去 F/G 交互，**≥80** 失去移动能力，**寒冷 100** 冻倒送医（住院费 ¥300，回医院重生）。躲进车里 / 便利店 / 加油站等取暖点可回暖；非冬季不累积寒冷。
- **违章追捕（🚨）**：开车**闯红灯一律触发通缉**（路口有交警再罚 ¥150）；**开车撞人**引来追捕警车——现在违章驾驶也会被警察追了。
- **买房系统（🏠 全新）**：13 个地图（上海 12 区 + 沈阳）各有 1~2 个楼盘（公寓/洋房/别墅/大平层/住宅，陆家嘴滨江大平层 ¥60,000 起，中海城住宅 ¥6,000 起步）。靠近地图上的楼盘按 **F** 看房：现金足够即买入，**每 30 秒自动收房租（跨区照收）**；已购房产可在 **B**「🏢 资产经营」菜单里「🚪 回家」（传送回房门口）或**出售**（回收 50%）。买房是合法资产，不受通缉/天气限制。
- **红绿灯与交通（🚦）**：各主城区主路交叉口放置信号灯，8 秒换向（东西绿 ↔ 南北绿）。**NPC 车会等红灯**（绿灯放行）；追捕警车与任务车闯红灯（符合设定）。玩家开车闯红灯：路口有 👮 交警会被开罚单（¥150，已有通缉则通缉 +1 星），无交警则提醒。
- **交警（👮）**：深蓝制服交警站在红绿灯路口旁指挥交通，按 G 可与交警交谈（交通提示）；闯红灯被其拦截会罚款。
- **被创会死（💥）**：步行时不要乱穿马路——被车速 ≥10 格/秒的车（普通车/巡逻警车）撞到会**昏迷送医**（住院费 ¥300，传回安全点重生）；**只有站在道路上才会被创**（人行道/广场/草坪是安全区）；被追捕警车撞到则走「逮捕」逻辑（罚款进警局）。开车时被撞只减速不受创。出生点/读档/下车/逮捕重生/失物包裹一律矫正到**非道路可走格**，杜绝"重生在路中央立刻再被创"的循环。
- **追捕撤离（🚨）**：被捕或被创送医后，追捕警车全部撤离转巡逻——不会出现"重生后立刻又被抓"的无限循环；玩家开车闯红灯：路口有 👮 交警会被开罚单（¥150，已有通缉则通缉 +1 星），停着等红灯不会被罚，高速掠过路口 ±1 格也会被检测到。
- **昼夜循环**：2 分钟一天，白天夜晚色调变化，HUD 显示游戏时间。
- **季节与天气 HUD**：右上角显示当前季节（春/夏/秋/冬）；台风/降雪/严寒时左上角显示实时状态（如「台风 12 级」「大雪」「寒冷 82」），档位区显示当前档位、倒档/空档/转向灯/漂移指示。
- **迷你地图**：右上角实时缩略图（玩家白点 / 任务黄点 / 最近交互绿点）。
- **生涯统计**：游玩时长、完成任务、被捕次数、**被车撞进医院次数、交通罚单张数**、累计移动、累计收入，跨会话保存。
- **存档**：浏览器 localStorage 自动/手动存档，产业所有权与生涯统计跨区保留。

## 🗺️ 地图设计

- 布局还原、面积压缩：每区 400×400 格（1 格 ≈ 8px），地标、水域（黄浦江、苏州河、滴水湖、长江口、丁香湖）、道路关系按真实相对位置生成。
- **区划形状**：每区配置 `shape` 多边形（0~1 归一化坐标），生成时区外格填充为**暗色空白**（OUTSKIRT，不可走、无绿化带），自然水体保留；出生点/交互点自动矫正到形状内（本轮已重做全部 shape，所有地标/产业/任务/警局/传送/楼盘/出生点均落在区界内，杜绝"重点区域跑到边界外"）。
- **滨江临海**：滨江区（杨浦/虹口/黄浦/徐汇/陆家嘴/世博/前滩/临港）形状延伸至江岸，江面加宽；**崇明四面环海**（全矩形区界+四侧水域圈出岛屿，无郊野）；**临港南临杭州湾、东临东海**。
- **水上不自动升路**：道路网格遇到水域直接断头（不再自动架桥），仅在显式配置处架桥——杨浦复兴岛运河 y344 定海桥（`water.bridgeY`）；崇明四面环海无桥，靠城市传送进出。
- **边界跨区传送**：各区配置 `borders` 邻接表，走到行政区边界（区界内缘沿边通行带已清空保证可达）按住对应方向键即无缝进入相邻行政区，落点自动矫正；水上/桥上边界不触发传送。
- **江中岛**：水域矩形支持 `island` 排除（水中陆地），杨浦东南黄浦江中为**复兴岛**（可探索空地+岛内便利店+复兴岛公园），岛西侧为**复兴岛运河**，东侧为黄浦江主航道。
- 支持矩形水域 + 圆形/椭圆水域（临港滴水湖、沈阳丁香湖）、公园绿地（`greens`）、住宅小区内部结构（`estates`，中海城）。
- 总览图：黄浦江隔开浦西/浦东，崇明为北部岛屿，临港在东南，走上去按 F 进入。

## 🚀 运行方式

### 本地直接玩
双击 `index.html` 用浏览器打开即可（推荐 Chrome/Edge）。

### 部署到 Netlify（免费，生成分享链接）
方式一 · 拖拽（最简单）：
1. 打开 [app.netlify.com/drop](https://app.netlify.com/drop)
2. 把整个 `gta-shanghai` 文件夹**拖进去**
3. 稍等几秒即生成 `https://xxx.netlify.app` 链接，把链接发给朋友就能玩

方式二 · Netlify CLI：
```bash
npm i -g netlify-cli
netlify deploy --dir gta-shanghai --prod   # 首次需登录授权
```
或先 `netlify deploy --dir gta-shanghai` 生成预览链接。

> 注意：无需构建步骤、无服务器，纯静态托管。存档存在各玩家自己的浏览器里，互不影响。

## 🛠️ 技术要点（供二次开发）

- 性能：每张地图生成后预渲染为整张离屏位图（3200×3200），运行时仅裁剪可视区域绘制，流畅 60fps；迷你地图复用同一离屏位图做缩放绘制。
- 存档：`localStorage` 键 `gta-shanghai-save-v1`（进度）+ `gta-shanghai-stats-v1`（生涯统计），跨区产业所有权存于 `ownership` 字段。
- 新增行政区/城市：在 `js/config.js` 的 `MAPS` 中加一段配置（道路间距/水域矩形/`shape` 多边形/地标/产业/任务/警局/传送点/出生点）即可，地图自动生成；传送面板自动出现入口。
- 新增任务类型：在 `CONFIG.TASK_TYPES` 加定义 + `js/world.js` 的 `startTask/updateTask` 加对应分支 + 区配置里加任务点。
- 交通玩法：红绿灯在 `mapgen.genTrafficLights` 生成（主路交叉口，`map.trafficLights`）；相位由 `world.trafficPhase` 按游戏时间推导；`Car.updateNpc` 红灯停车、`World.checkRedLight` 玩家闯红灯（一律 +1 星追捕）、`World.checkCarCrash` 被创死亡、`spawnTrafficPolice` 生成交警。阈值在 `CONFIG.TRAFFIC`。
- 驾驶模拟：档位极速/空档滑行/手刹/漂移参数在 `CONFIG.DRIVE`；漂移胎痕存 `world.driftMarks`；季节（`CONFIG.SEASONS.len` 天/季）与天气（台风/雪概率、风力、雪量）在 `CONFIG.WEATHER`，沈阳严寒在 `CONFIG.COLD`，实现于 `World.updateWeather/updateCold/freezeDeath`。
- 买房系统：楼盘配置在 `MAPS[区].homes`（name/type/price/rent/x/y），类型与收租周期在 `CONFIG.HOME_TYPES / HOME_RENT_CYCLE`；所有权存 `HOME_OWNERSHIP`（存于存档 `homes` 字段，旧档兼容默认空）；购买/出售/回家在 `UI.buyHome/sellHome/goHome`，收租在 `World.update` 的 `rentTimer` 结算；楼盘渲染与 `businesses` 同层。回家支持**跨区**（B 菜单跨区房产点回家自动传送并保留全局所有权）、**即存档**、**下车车转回巡逻**、**沈阳冬天回暖**；换区不丢房（`restoreHomes` 仅在读档时重置全局所有权，并对旧坏存档的数组型 `homes` 字段做纠正）。
- 车辆脱困：`Car.tryDir` 与 `move` 用**同一车头角探测公式**（`probe = r + max(mv,4)`），确保「探测可走 ⇔ 移动可走」逐位一致，杜绝车卡墙死循环；死胡同由 `reverseOut` 掉头向来路倒车兜底。
- 测试：`node test/smoke.js && node test/logic.js`（逻辑测试已 mock DOM 环境，可离线跑；含驾驶/漂移/台风/雪季/严寒/违章追捕/买房/收租/回家/卖房/楼盘点位用例）。
